## 🎯 HOW TO USE

### Quick Start:
1. Open project in Godot 4.2+
2. Press F5 to run
3. WASD to move
4. E to interact
5. 1/2/3 for tools
6. B for shop
7. F5 to quick save
8. F9 to quick load

### For Players:
```
WASD - Move
E - Interact
1 - Hoe (till soil)
2 - Watering Can
3 - Axe
B - Shop
I - Inventory
C - Build Menu
ESC - Settings
F5 - Quick Save
F9 - Quick Load
F11 - Fullscreen
```

### For Developers:
```gdscript
# Save game
SaveSystem.save_game(0)
SaveSystem.auto_save()
SaveSystem.quick_save()

# Load game
SaveSystem.load_game(0)
SaveSystem.quick_load()

# Effects
ParticleManager.create_particle_effect(pos, "harvest", parent)
AudioManager.play_sfx("water")
TweenHelper.bounce(node, 0.5)

# Performance
PerformanceMonitor.enable_low_performance_mode()

# Notifications
ModernHUD.show_notification("✨ Success!", Color.GREEN)
```
